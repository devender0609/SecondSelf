# SecondSelf v40 Lean Commit Tool

This version intentionally removes clutter and keeps the product focused on practical commitment checks.

Main changes:
- Home is positioned around Check / Compare / Find, with Check first.
- Removed the Smart Intake box and extracted-summary screen from the primary flow.
- Result view is shorter: Best Move, options if relevant, Choose this if, Regret warning, Why this works, Check carefully, Ask before you commit.
- Hid redundant visible panels such as score explainer, confidence box, proof/evidence panels, passport, and extra innovation cards.
- Trip planner no longer shows fake map pins or multiple fake ranked trip plans; it gives one draft plan and clearly says what must be verified.
- Maps only appear for actual place-style results.
- Live data status is explicit: place data may be live, but prices/availability/fees/terms are not verified unless a real pricing API is connected.
