# SecondSelf v35 Smarter Engine

Updates added on top of v34:

- Improved compare parsing: extracts price, fit signals, risk signals, and clearer per-option next steps from pasted choices.
- Added score breakdown: each selected option now shows what raised and lowered its score.
- Added comparison insight: explains why the currently selected option is ahead of the next option and when the backup may still be better.
- Kept missing-detail validation: travel requires dates, map/place results require location, Quote Audit requires amount/details, Compare requires at least two choices.
- Feedback learning remains active: user feedback updates learned likes/avoid signals locally and influences future scoring.
- Result language remains practical and low-jargon.

Build checked with npm run build.
