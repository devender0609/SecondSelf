# SecondSelf v30 Smart Ask / Low-Typing Upgrade

Updated from the uploaded v29 build.

## Main UX change
The app now uses Smart Ask as the primary workflow:

1. User types naturally.
2. SecondSelf extracts action, category, mode, location, budget, need, and must-haves.
3. Instead of showing a long form, the app shows a compact **We understood this** summary.
4. User only adds missing/important details with quick chips and short fields.
5. Advanced filters remain available but collapsed.

## Why
This avoids the redundant experience where a user types a full request and then still has to complete a full structured form.

## Still preserved
- Guided Find / Compare / Check flow
- Profile-first ranking
- Budget logic fixes
- Thorough audit logic from v27/v29
- Map results when appropriate
